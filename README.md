# AI Synonym Swapper для SillyTavern

Расширение, которое **визуально** заменяет нежелательные слова-клише (например, «собственничество») в сообщениях на синонимы, подобранные вашей текущей ИИ-моделью. Работает по принципу встроенного переводчика: оригинальный текст в файле чата не изменяется, подмена происходит только в отображении (`display_text`).

## Возможности

- Добавление любого количества нежелательных слов (по одному или списком через запятую).
- Автоматическая обработка новых сообщений персонажа (и, опционально, ваших сообщений).
- ИИ каждый раз подбирает **разные** синонимы с учётом контекста и грамматики.
- Учитываются грамматические формы слов («собственничество» → найдёт и «собственничеством», «собственничества» и т.д.).
- Ручные кнопки: обработать последнее сообщение, обработать весь чат, вернуть оригинал.
- Обработка свайпов (альтернативных вариантов ответа).
- Все настройки сохраняются между сессиями.

## Установка через GitHub

1. Создайте новый **публичный** репозиторий на GitHub (например, `st-synonym-swapper`).
2. Загрузите в него файлы этой папки: `manifest.json`, `index.js`, `style.css`, `README.md`.
3. Откройте SillyTavern → нажмите на иконку **«Расширения»** (три сложенных блока в верхней панели).
4. Нажмите **«Install extension»** (кнопка со стрелкой вниз в правом верхнем углу панели).
5. Вставьте ссылку на ваш репозиторий, например:
   ```
   https://github.com/ВАШ_НИК/st-synonym-swapper
   ```
6. Нажмите **Install** — расширение появится в списке.

### Альтернативная установка (вручную, без GitHub)

Скопируйте папку `st-synonym-swapper` в:
```
SillyTavern/data/default-user/extensions/st-synonym-swapper
```
и перезагрузите страницу SillyTavern.

## Использование

1. Откройте панель **Расширения** → найдите блок **AI Synonym Swapper**.
2. Убедитесь, что стоит галочка **«Включено»**.
3. Введите нежелательное слово (например, `собственничество`) и нажмите **+** или Enter.
4. Готово! Все новые сообщения, содержащие это слово, будут автоматически перефразированы.
5. Для уже существующих сообщений нажмите **«Последнее»** или **«Весь чат»**.
6. Кнопка **«Оригинал»** возвращает исходный текст.

## Важно знать

- Расширение использует **вашу текущую подключённую модель** (тот же API-ключ, что и для чата). Каждая обработка сообщения — это один дополнительный запрос к API.
- Оригинал сообщения всегда сохраняется — в контекст для ИИ при генерации ответов уходит **исходный** текст, а не заменённый.
- Слова вводите в начальной форме — формы слова находятся автоматически по основе.
